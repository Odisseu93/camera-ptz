# Contributing Guide

## Branching Workflow
- This repository uses Gitflow:
  - `main`: Production-ready releases.
  - `develop`: Integration branch for tested features.
  - `feature/<name>`: Individual feature branches.
  - `release/<version>`: Release preparation branches.

## Coding & Commit Standards
- Follow Conventional Commits format (`feat:`, `fix:`, `refactor:`, `docs:`, `chore:`, `security:`).
- Type hint all public interfaces.
- Comply with Anti-AI-Slop standards defined in `GEMINI.md`.
