# Git Conventions & Workflow

- Methodology: Gitflow (branches `main`, `develop`, `feature/*`, `release/*`).
- Versioning: Semantic Versioning (SemVer 2.0.0).
- Commit Format: Conventional Commits (`feat:`, `fix:`, `refactor:`, `docs:`, `chore:`, `security:`).
- Atomicity: Keep commits focused on a single logical change.
- Clean History: No stray debug files, untracked test scripts, or committed `.env` files.
